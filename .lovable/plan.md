
# Fill AI — Редизайн интерфейса

## 🎨 Визуальная концепция

**Стиль:** Тёмный премиальный AI-интерфейс с фиолетово-синим градиентом (вдохновлено Cursor / Anthropic / Linear).

**Палитра:**
- Фон: глубокий чёрно-синий `#0A0A14` с лёгкой виньеткой
- Поверхности: полупрозрачные glass-карточки с тонкой границей
- Акцент: градиент `indigo → violet → fuchsia` (#6366F1 → #8B5CF6 → #D946EF)
- Текст: мягкий белый + приглушённый серо-голубой для второстепенного

**Типографика:** Inter / Geist для UI, тонкие крупные заголовки в hero. Поддержка кириллицы.

**Эффекты:** субтильные градиентные свечения за hero-блоком, плавные micro-анимации на hover, glow вокруг активных элементов, floating orbs на фоне.

---

## 🧭 Навигация и каркас

**Сайдбар (редизайн):**
- Логотип Fill AI с маленькой градиентной иконкой-искрой
- Пункты: Новый курс · Мои курсы · Профиль (с иконками Lucide, активный пункт — градиентная подсветка слева + лёгкий glass-фон)
- Внизу: карточка пользователя (аватар с градиентным кольцом, имя, email, мини-меню)
- Переключатель сворачивания + переключатель языка RU/EN
- Кнопка "Тёмная/светлая тема" (по умолчанию тёмная)

## 📄 Экраны (редизайн каждого)

### 1. Новый курс (Hero генерации)
- Крупный заголовок "Что хотите изучить?" с тонким шрифтом и градиентной подсветкой одного слова
- Подзаголовок становится более лёгким и воздушным
- **Поле ввода:** большая glass-карточка с мягким свечением по периметру при фокусе, плейсхолдер ротируется (печатающаяся анимация с примерами тем)
- Кнопки внутри: "Прикрепить" (иконка скрепки), "Создать" — градиентная кнопка со стрелкой и лёгким glow
- **Чипы примеров тем** — больше, с тонкими иконками (Python, лидерство, финансы, английский, шахматы и т.д.), на hover поднимаются
- Снизу — лёгкая подпись "ИИ сам подберёт формат: код, квизы, карточки или диаграммы"
- Фоновые floating orbs с blur для атмосферы

### 2. Мои курсы
- Заголовок + счётчик курсов справа
- **Поиск** с иконкой и горячей клавишей `⌘K`
- **Фильтры:** табы вместо UUID-чипов — "Все · В процессе · Завершённые · По уровню" + сортировка
- **Сетка карточек курсов:**
  - Обложка-градиент с тематической иконкой (генерируется по категории)
  - Бейдж уровня с цветовым кодом (beginner/intermediate/advanced)
  - Название, краткое описание
  - Прогресс-бар с градиентной заливкой и %
  - Низ: длительность, кнопки "Продолжить" (primary) + меню (⋯ удалить/поделиться)
  - Hover: лёгкий подъём + свечение границы
- Пустое состояние с CTA "Создать первый курс"

### 3. Профиль и геймификация
- **Hero профиля:** крупный аватар с градиентным кольцом уровня, имя, статус, "Member since"
- **Прогресс уровня:** широкий градиентный бар с подписью XP до следующего уровня
- **Метрики (4 карточки):** Total XP · Day Streak 🔥 · Курсы завершены · Часы обучения — каждая с иконкой, мини-трендом и подписью
- **Табы:** Обзор · Обучение · Созданные · Достижения · Аналитика
  - **Обзор:** крупные числа + последние действия (timeline)
  - **Достижения:** сетка бейджей (заблокированные с blur), редкие — с особым свечением
  - **Аналитика:** график активности (heatmap по дням, как GitHub) + распределение по темам
- Кнопки Edit Profile / Logout — отдельно справа в шапке

### 4. Внутренний просмотр курса (новый)
- **Сайдбар уроков** слева: список модулей с прогрессом, текущий — подсвечен градиентом
- **Центральная область:**
  - Заголовок урока, тип контента, оценка времени
  - Контент-блоки markdown (читаемая ширина ~720px), красивые code-блоки с подсветкой
  - **Адаптивные интерактивные блоки** (ИИ выбирает по теме):
    - 💻 Код — встроенный редактор + кнопка "Запустить" + панель вывода
    - ❓ Квиз — карточки вариантов с мгновенной обратной связью (зелёный/красный glow)
    - 🃏 Flashcards — переворачивающиеся карточки
    - 📊 Диаграмма / drag-n-drop — для концептов
- **Низ:** кнопки "← Назад" / "Дальше →", прогресс модуля, начисление XP с анимацией при завершении
- Топбар: хлебные крошки + "Выйти из курса"

## ⚙️ UX-принципы
- Один CTA на экране — никакой визуальной перегрузки
- Все состояния (загрузка, пусто, ошибка, успех) продуманы со skeleton-ами и toast-ами
- Полная адаптивность: мобильный сайдбар как drawer, карточки в одну колонку
- Доступность: контраст AA+, фокусные кольца на всех интерактивных элементах
- Микроанимации только там, где они помогают (hover, focus, success), без перебора
